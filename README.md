### 🏗️ Öne Çıkan Proje

#### **Kurumsal Depo Yönetim Sistemi (Full-Stack Inventory Management)**
Modern işletmeler için gerçek zamanlı stok takibi, kritik stok uyarıları (`<5` adet), tarih-saat damgalı işlem denetim geçmişi ve tek tıkla Excel (CSV) raporlama sunan canlı kurumsal web platformu.

- **Teknoloji Yığını:**
  - **Backend:** Java, Spring Boot, Spring Data JPA (Hibernate)
  - **Frontend:** React (Vite), Material-UI (MUI), React Router DOM
  - **Veritabanı & Bulut:** MySQL, Railway (Backend + DB), Vercel (Frontend)
- 🌐 **Canlı Uygulama:** [kurumsal-depo-yonetim.vercel.app](https://kurumsal-depo-yonetim.vercel.app)
